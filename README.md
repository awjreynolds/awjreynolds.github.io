# awjreynolds.github.io

GitHub Pages index for public projects.

## Projects

- `stats19-spike/` - archived DfT STATS19 road safety data explorer spike.
- `atm-prioritisation/` - separate ATM prioritisation prototype published under the same GitHub Pages domain.

The root `index.html` is a lightweight directory index. New public projects can
live in their own top-level directory, for example `/<project>/`, and be linked
from the root page.
